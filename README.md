# CSC 305 Lab 1: Git Practice

A practice repository for Lab 1 of CSC 305 at Augustana College. It was created to experiment with Git and GitHub, so it contains no source code, only this README.

## What the lab covered

- Committing changes from a local clone
- Editing a file directly on GitHub
- Making a change on a separate branch and merging it through a pull request

The commit history shows each of these steps.
